## Unterstützte Kubernetes-Versionen

In unserem Managed-Kubernetes-Service stellen wir sicher, dass Ihre Cluster immer mit unterstützten und stabilen Kubernetes-Versionen laufen.

Damit unsere Richtlinie für den Versionssupport klar ist, zeigt die folgende Übersicht unsere unterstützten Kubernetes-Versionen mit ihren Daten für Abkündigung und End-of-Life (EOL).

| Version | Abkündigung | End-of-Life |
|---------|-------------|-------------|
| v1.36   | offen       | offen       |
| v1.35   | offen       | offen       |
| v1.34   | offen       | offen       |
| v1.33   | 2026-07-29  | 2026-11-02  |
| v1.32   | 2026-02-25  | 2026-05-31  |
| v1.31   | 2025-11-18  | 2026-02-01  |
| v1.30   | 2025-09-01  | 2025-12-01  |

## Richtlinie für erzwungene Upgrades

Wenn der Eigentümer einen Kunden-Cluster nicht bis zum angekündigten End-of-Life-Datum aktualisiert, erhält der Cluster automatisch ein Upgrade auf die nächste unterstützte Version.

Mehr über die Abkündigungsrichtlinie und die Richtlinie für erzwungene Upgrades finden Sie [hier](/managedk8s/clusterlifecycle/deprecationpolicy/).
